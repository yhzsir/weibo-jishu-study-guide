专题：无耗网络Z矩阵的性质推导

本专题是第5章"网络矩阵性质"的严格数学推导补充，考试中常以"证明/简答"形式考查结论，建议理解推导逻辑而非死记最终公式。

推导目标

知识点 对于一个无耗N端口网络，证明其阻抗矩阵[Z]必须满足特定的对称/反对称关系。

出发点：无耗网络净吸收的平均功率为零
P_av = (1/2)·Re[ΣᵢUᵢIᵢ*] = (1/2)·Re[I†ZI] = 0　（对任意激励电流向量I均成立）

推导步骤

知识点 展开 I†ZI = Σ_m Σ_n I_m* Z_mn I_n，分两种情况讨论：

情况1：m = n（对角元）

P_av 中 m=n 的项为 (1/2)|I_n|²·Re[Z_nn]
由于对任意|I_n|≠0该项的实部贡献必须可被其余交叉项抵消为零，分析可得：
Re[Z_nn] = 0　（对角元必为纯电抗，无耗元件自阻抗不能有实部）

情况2：m ≠ n（交叉项）

令 Z_mn = R_mn + jX_mn，Z_nm = R_nm + jX_nm，设 I_m*I_n = a + jb（a、b为任意实数，因为I可任意选取）。代入功率表达式并要求对任意a、b都成立：

Re[I_m*I_n Z_mn + I_n*I_m Z_nm] = a(R_mn+R_nm) + b(X_mn−X_nm) = 0　对任意a,b成立
⟹ R_mn + R_nm = 0　且　X_mn − X_nm = 0

即：R_mn = −R_nm（电阻部分反对称），X_mn = X_nm（电抗部分对称）。

结论

无耗网络：R_mn = −R_nm，X_mn = X_nm，Re[Z_nn] = 0
若网络同时满足互易（Z_mn = Z_nm，见S矩阵对称性专题的互易定理）：
⟹ R_mn = R_nm 且 R_mn = −R_nm ⟹ R_mn = 0（任意m,n）
结论：无耗+互易网络的[Z]矩阵为纯虚矩阵，且满足 [Z] + [Z]† = 0（即[Z]为反厄米矩阵的特殊情形——此处因矩阵为纯虚对称矩阵，[Z]* = −[Z]）
考点："无耗"和"互易"是两个独立条件，必须同时满足才能得到"Z矩阵纯虚"的强结论；仅无耗不互易（如非互易无耗器件）只能得到 R_mn=−R_nm 的反对称关系，不能推出R_mn=0。
讲解分析：该推导的核心技巧是"利用电流向量的任意性"——因为I_m、I_n的幅度和相对相位可以任意选取（即a、b独立可变），功率为零这一个标量方程，被拆解出两个独立的矩阵元素约束（实部、虚部各自为零），这是电磁网络理论中"任意性论证"的典型范式，与S矩阵幺正性/对称性证明中"任意激励向量"的论证思路完全一致，建议对照学习。
