第3章 规则金属波导

本章脉络：3.2-3.3 导波原理与矩形波导（纵向场法求解TE/TM模）→ 3.4 圆波导 → 3.5 波导的激励与耦合。核心方法是场分析法：从无源区麦克斯韦方程组出发，推导亥姆霍兹方程，用"纵向分量求解+横向分量表示"的套路得到各模式场分布。

3.2-3.3 导波原理与矩形波导

知识点 求解思路三步走（考试常考"简答"）：

  1. 由无源区麦克斯韦方程组导出 E、H 满足的亥姆霍兹方程（∇²E+k²E=0）；
  2. 利用波导轴向传输假设，把纵向分量 E_z、H_z 分离变量求解（纵向分量方程是标量亥姆霍兹方程，边界条件简单）；
  3. 用纵向分量反推横向分量（E_x、E_y、H_x、H_y 可完全由 E_z、H_z 线性表出），再代入边界条件定出波型。
矩形波导（a×b，a>b）TE_mn / TM_mn 模：
截止波数：k_c = √[(mπ/a)² + (nπ/b)²]
截止波长：λ_c = 2 / √[(m/a)² + (n/b)²]
相移常数：β = √(k² − k_c²) ，k=2πf/c = 2π/λ
TE_mn：m、n 不能同时为0；TM_mn：m、n 都不能为0（否则场全为零）

知识点 TE₁₀主模：m=1,n=0,是截止波数最小（λ_c最大=2a）的模式，是矩形波导中最先导通、单模传输时唯一使用的模式。

TE₁₀模场分量（仅含 E_y, H_x, H_z）：
E_y = E₀ sin(πx/a) e^(−jβz)
λ_c(TE10) = 2a ；单模传输条件：a < λ < 2a（大致范围，需同时保证高次模截止、低次不出现消逝）
考点：简并模 —— TE_mn 与 TM_mn（m,n均不为0）具有相同的 λ_c，二者在矩形波导中为简并模；但单独的 TE_m0 或 TE_0n 没有对应的简并 TM 模（因为 TM 要求 m,n 均非零）。

知识点 相速与群速（有色散）：

相速：v_p = ω/β = c / √(1−(λ/λ_c)²) > c（波导中相速可超光速，但不违反相对论——能量不是以相速传播）
群速：v_g = c · √(1−(λ/λ_c)²) < c（能量/信息传播速度）
v_p · v_g = c²
讲解分析："相速超光速"是本章最容易引发误解的点。相速只是等相位面移动的速度，并不传递能量或信息；真正携带能量的是群速，恒小于光速，物理上自洽。可类比"剪刀交点移动速度可超光速"的经典科普例子帮助理解。

知识点 波导衰减：工作于截止频率以下时，β变为虚数，波按 e^(−αz) 指数衰减，称为截止模/消逝模——这解释了"为什么叫截止波长"：高于截止频率的模式才能真正传导，低于的则在源附近迅速衰减为零。实际衰减还包括导体损耗和介质损耗两部分（见衰减常数α的工程计算公式）。

3.4 圆波导

知识点 圆波导场解用贝塞尔函数描述，TE_mn、TM_mn 截止波长由贝塞尔函数（导数）的零点决定：

TM_mn：λ_c = 2πa / p_mn （p_mn 为 m 阶贝塞尔函数 J_m 的第 n 个零点）
TE_mn：λ_c = 2πa / p'_mn （p'_mn 为 J_m' 的第 n 个零点）
模式归一化零点λ_c/a说明
TE₁₁p'₁₁=1.84123.4126圆波导主模，λ_c最大
TM₀₁p₀₁=2.40492.6127次低模，常用于定向耦合、圆极化器
TE₀₁p'₀₁=3.83171.6398低损耗模，用于远距离传输（如毫米波传输系统）
考点：为什么圆波导主模是 TE₁₁ 而不是 TE₀₁？ 按照截止波长公式逐一计算对比可知 TE₁₁ 的 λ_c 最大（p'₁₁=1.8412 最小），因此截止频率最低，最先导通，为主模；TE₀₁ 虽然低损耗（常用于毫米波长距离传输），但不是最低次模。

知识点 圆波导的两类简并（重要辨析）：

类型定义后果
模式简并不同(m,n)模式有相同λ_c，如 TE₀n 与 TM₁n与矩形波导类似，是"无关模式、巧合同频"
极化简并m≠0时，场可绕轴任意取向（sin mφ / cos mφ 两种极化同时存在且同频）波导轴向稍有不均匀即引起极化面旋转，很难维持单一线极化的单模传输，是圆波导工程应用中的突出难题
讲解分析：极化简并是圆波导独有、矩形波导没有的问题（因为矩形波导的两个边长 a≠b 破坏了旋转对称性，天然区分了极化方向）。工程上常通过椭圆波导或加极化抑制筋来解决。

3.5 波导的激励与耦合

知识点 激励（把外部信号转为波导内的场）与耦合（从波导中提取场能量）互为逆过程，分析方法通用。三种常见激励方式：

方式原理激励模式要点
电激励（探针）短探针插入波导，平行于待激励模式的电场方向探针方向应与所需模式E场方向一致，位置选在该模式场强最大处
磁激励（环/耦合环）小环法向与待激励模式磁场方向一致，感应磁场激发对应模式环面法线方向对准所需模式H场方向
孔缝激励（小孔耦合）公共壁上开小孔，两侧场通过孔缝耦合可做成定向耦合器（第6章具体器件）
讲解分析：课件中"没有手指（琴师），如何评价琴？没有激励，如何评价波导？"这句话点出了本节的教学目的——前面(3.2~3.4)求的是波导的"本征解"（无激励时能支持哪些模式），本节解决"如何在实际中把能量送入/引出指定模式"的工程问题，两者合起来才是完整的波导理论。
